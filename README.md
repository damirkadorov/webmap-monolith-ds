# WebMap Monolith-DS

Интерактивная веб-карта и каталог кораблей/станций для билда Space Station 14: **Monolith-DS** (`https://github.com/Lua-Frontier/Monolith-DS`).

## Возможности

- Полный каталог шаттлов, кораблей и POI-станций с фильтрацией по:
  - Верфям / фракциям (ТСФ, СССП, Колосс-Централ, Династия Фаэтон, Синдикат, Экспедиционные, Мусорная верфь и др.)
  - Классам корпуса (линкор, авианосец, крейсер, эсминец, фрегат, корвет, истребитель, шаттл, станция)
  - Специализациям / ролям (боевой, шахтёрский, научный, медицинский, транспортный и др.)
  - Типам двигателей (ДАМ, ТЭГ, плазма, уран, ВСУ и др.)
  - Размерам и статусу продажи
- Детальный просмотр каждого шаттла с характеристиками, двигателями, вооружением и высококачественными планами палуб
- Адаптивный интерфейс для настольных и мобильных устройств (Svelte 5 / SvelteKit / TailwindCSS)
- Поддержка развертывания на **Vercel** и **GitHub Pages**

## Установка и запуск

```bash
# Установка зависимостей
pnpm install

# Запуск в режиме разработки
pnpm dev

# Сборка проекта
pnpm build

# Локальный предпросмотр сборки
pnpm preview
```

## Обновление данных из билда Monolith-DS

Для повторной экстракции всех прототипов и локализаций из локального билда:

```bash
node scripts/extract-monolith-data.js
```
